Who We Are

Who We Are

Team Vibes Coding is a team of three first-year Bachelor of Science in Information Technology (BSIT) students at DNSC - Island Garden City of Samal Campus. We are beginner web developers who learn and build together.

Our Purpose

We formed this team to practice coding, share what we learn, and build websites that we can be proud of. This portfolio shows our team and our progress as beginner developers.

Our Goals

  • Understand how HTML and CSS work.
  • Build projects together as a team.
  • Improve our skills a little every day.

Our Interests and Journey

We are interested in technology, web design, and how websites are made. Our journey has just started, and we are excited to see how far we can go.

What We Are Studying Now

HTML

HTML5

The language that gives a web page its structure, like headings, paragraphs, and images.

CSS

CSS3

The language that controls colors, fonts, spacing, and the look of a page.

JS

JavaScript Fundamentals

We have not started yet. These are the basic ideas of programming that make websites interactive.

RWD

Responsive Web Design

Making a website look good on phones, tablets, and computers.

LAYOUT

Website Layout

Arranging sections, cards, and text so a page is neat and easy to read.

UI/UX

Basic UI/UX Design

Designing pages that look nice and are easy for people to use.

GIT

Version Control with Git and GitHub

Saving the history of our code and sharing it as a team.
